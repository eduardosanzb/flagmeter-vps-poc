How to Write Slides

Create a .en.md file inside content/slides/. Define your slides as a YAML array in the frontmatter. Each slide needs a type that determines its visual layout.

Frontmatter Schema

---
title: "My Deck Title"
description: "Short description shown on the index"
slides:
  - number: 1
    type: hero
    label: "Section Label"
    title: "BIG SLIDE TITLE"
    subtitle: "Supporting line under the title"
    # ... type-specific fields (see below)
---
hero Title slide with bullets + terminal CTA 
type: hero
bullets: ["60% cost cut", "2-day ownership"]
cta: "raus.cloud --audit --free"
two-col Two panels: green ✓ list / red ✗ list 
type: two-col
col_a:
  heading: "✓ This IS for you"
  items: ["5-15 engineers", ...]
col_b:
  heading: "✗ This is NOT for you"
  items: ["Need multi-region", ...]
terminal Terminal prompt with conditional outcomes 
type: terminal
prompt: '"Who owns your PagerDuty?"'
outcomes:
  - answer: '"We all do"'
    result: "Alert fatigue. No ownership."
conclusion: "One resignation away from outage."
diagnosis Comparison cases with root cause conclusion 
type: diagnosis
cases:
  - answer: '"We all do"'
    tag: "Complexity > ownership"
    description: "Everyone is on-call..."
conclusion: "Root cause: ..."
layers Numbered cascade layers 
type: layers
layers:
  - number: 1
    category: "Financial"
    description: "€70k-90k/yr on..."
stat-grid 3 big stats + detail explanation boxes 
type: stat-grid
stats:
  - value: "€80k"
    label: "annual shadow ops cost"
details:
  - heading: "The Hidden DevOps Payroll"
    body: "Last week's incident..."
code-block Terminal code pane + stat bullets 
type: code-block
code: |
  $ cat stack.yml
  Hetzner CPX51   €50/mo
bullets:
  - value: "60%"
    label: "cost reduction"
footer: "No IAM. No YAML hell."
timeline Multi-week columns with checklists 
type: timeline
weeks:
  - number: "01"
    heading: "Audit + Setup"
    items: ["Free audit", "Identify waste"]
footer: "Deploy: git push."
promise 3 large commitment cards 
type: promise
promises:
  - value: "60%"
    heading: "Cost cut."
    body: "Right-sized infrastructure..."
feature-list 2-column bold feature items 
type: feature-list
features:
  - heading: "Business-First Architecture"
    body: "We design around your needs..."
pricing Engagement tiers with price + duration 
type: pricing
tiers:
  - number: "01"
    name: "Architecture Audit"
    description: "Find €2k+/mo waste."
    price: "Free"
    duration: "15 min call"
proof Case study cards with result headline 
type: proof
cases:
  - client: "Unity (SaaS)"
    result: "€70k/year saved"
    body: "Fixed CloudWatch retention..."
steps Numbered action flow 
type: steps
tagline: "You're a peer, not a salesperson."
steps:
  - number: 1
    action: "ASK"
    description: '"What was your last fire?"'
cta Final call-to-action with website + email 
type: cta
website: "raus.cloud"
email: "hello@raus.cloud"
tagline: "Right-sized. Business-first."
